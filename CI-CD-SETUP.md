# GitHub Actions CI/CD Workflow Setup\n\nThis document provides the CI/CD workflow configuration for Givy. Due to permission constraints, you'll need to manually create the workflow file in your repository.\n\n## Setup Instructions\n\n### Step 1: Create Workflow Directory\n\nIn your repository root, create the directory structure:\n\n```bash\nmkdir -p .github/workflows\n```\n\n### Step 2: Add CI Workflow File\n\nCreate `.github/workflows/ci.yml` with the following content:\n\n```yaml\nname: CI/CD Pipeline\n\non:\n  push:\n    branches: [master, main]\n  pull_request:\n    branches: [master, main]\n\njobs:\n  lint:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v4\n      \n      - name: Setup Node.js\n        uses: actions/setup-node@v4\n        with:\n          node-version: '20'\n          cache: 'npm'\n      \n      - name: Install dependencies\n        run: npm ci\n      \n      - name: Run ESLint\n        run: npm run lint\n      \n      - name: TypeScript type check\n        run: npx tsc --noEmit\n\n  test:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v4\n      \n      - name: Setup Node.js\n        uses: actions/setup-node@v4\n        with:\n          node-version: '20'\n          cache: 'npm'\n      \n      - name: Install dependencies\n        run: npm ci\n      \n      - name: Run unit tests (Vitest)\n        run: npm run test\n      \n      - name: Upload coverage (optional)\n        uses: codecov/codecov-action@v3\n        if: always()\n        with:\n          flags: unittests\n          fail_ci_if_error: false\n\n  e2e:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v4\n      \n      - name: Setup Node.js\n        uses: actions/setup-node@v4\n        with:\n          node-version: '20'\n          cache: 'npm'\n      \n      - name: Install dependencies\n        run: npm ci\n      \n      - name: Install Playwright browsers\n        run: npx playwright install --with-deps\n      \n      - name: Build Next.js app\n        run: npm run build\n      \n      - name: Run E2E security tests\n        run: npm run test:e2e:security\n        env:\n          PLAYWRIGHT_BASE_URL: http://localhost:3000\n      \n      - name: Upload Playwright report\n        uses: actions/upload-artifact@v3\n        if: always()\n        with:\n          name: playwright-report\n          path: playwright-report/\n\n  security-scan:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v4\n      \n      - name: Run secret scanning\n        run: |\n          # Basic pattern matching for common secrets\n          if grep -r 'NEXT_PUBLIC_SUPABASE_ANON_KEY=' . --include='*.ts' --include='*.tsx' --include='*.js' --include='*.jsx' --exclude-dir=node_modules --exclude-dir=.next; then\n            echo \"⚠️  Warning: Potential secret found in source code\"\n            exit 1\n          fi\n          if grep -r 'OPENAI_API_KEY=' . --include='*.ts' --include='*.tsx' --include='*.js' --include='*.jsx' --exclude-dir=node_modules --exclude-dir=.next; then\n            echo \"⚠️  Warning: Potential secret found in source code\"\n            exit 1\n          fi\n          if grep -r 'sk-' . --include='*.ts' --include='*.tsx' --include='*.js' --include='*.jsx' --exclude-dir=node_modules --exclude-dir=.next | grep -v 'sk-' | head -5; then\n            echo \"⚠️  Review potential secrets above\"\n          fi\n          echo \"✓ Secret scan completed\"\n\n  build:\n    runs-on: ubuntu-latest\n    needs: [lint, test, e2e, security-scan]\n    steps:\n      - uses: actions/checkout@v4\n      \n      - name: Setup Node.js\n        uses: actions/setup-node@v4\n        with:\n          node-version: '20'\n          cache: 'npm'\n      \n      - name: Install dependencies\n        run: npm ci\n      \n      - name: Build production bundle\n        run: npm run build\n        env:\n          NEXT_PUBLIC_SITE_URL: https://www.givy.gifts\n      \n      - name: Verify build artifacts\n        run: |\n          test -d .next && echo \"✓ Next.js build successful\" || exit 1\n```\n\n## What This Workflow Does\n\n### 1. **Lint Job**\n- Runs ESLint on all TypeScript/JavaScript files\n- Performs TypeScript type checking\n- Fails if code quality issues are found\n\n### 2. **Test Job**\n- Runs unit tests via Vitest\n- Uploads coverage reports to Codecov (optional)\n- Verifies all security helpers and RLS functions\n\n### 3. **E2E Job**\n- Installs Playwright browser dependencies\n- Builds the Next.js app\n- Runs security-focused E2E tests\n- Uploads test reports as artifacts\n\n### 4. **Security Scan Job**\n- Scans for hardcoded secrets (API keys, tokens)\n- Prevents commits with sensitive data\n- Checks for common patterns: `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `OPENAI_API_KEY`, `sk-`\n\n### 5. **Build Job**\n- Runs only after all other jobs pass\n- Builds production Next.js bundle\n- Verifies `.next` directory exists\n\n## Running Locally\n\nYou can test the workflow locally using [act](https://github.com/nektos/act):\n\n```bash\n# Install act\nbrew install act\n\n# Run the workflow locally\nact -j lint\nact -j test\nact -j e2e\n```\n\n## Branch Protection Rules\n\nRecommended GitHub branch protection settings:\n\n1. Go to **Settings** → **Branches** → **Branch protection rules**\n2. Create rule for `master` and `main`:\n   - ✅ Require status checks to pass before merging\n   - ✅ Require all conversations to be resolved\n   - ✅ Dismiss stale pull request approvals when new commits are pushed\n   - Status checks to require:\n     - `lint`\n     - `test`\n     - `e2e`\n     - `security-scan`\n     - `build`\n\n## Troubleshooting\n\n### Workflow Failing on `npm run lint`\n\nEnsure your ESLint config is properly set up:\n\n```bash\n# Locally\nnpm run lint\n\n# Fix issues\nnpm run lint -- --fix\n```\n\n### E2E Tests Timing Out\n\nIncrease timeout in `.github/workflows/ci.yml`:\n\n```yaml\ne2e:\n  runs-on: ubuntu-latest\n  timeout-minutes: 15  # Add this\n```\n\n### Secret Scan False Positives\n\nUpdate the secret scanning regex patterns in the workflow if needed. For example, to ignore test fixtures:\n\n```bash\ngrep -r 'sk-' . --include='*.ts' --exclude-dir=node_modules --exclude-dir=.next --exclude='*.fixture.ts'\n```\n\n## Next Steps\n\n1. ✅ Create `.github/workflows/ci.yml` with the content above\n2. ✅ Push to `master` or `main` branch\n3. ✅ Verify workflow runs in GitHub Actions tab\n4. ✅ Set branch protection rules (see above)\n5. ✅ All future PRs will now run automated checks\n\n---\n\nFor questions, see the [GitHub Actions documentation](https://docs.github.com/en/actions).\n"
